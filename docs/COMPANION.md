# 小明同学：预算搭子

## 角色与素材
项目自绘的SVG角色：黄色票据帽、红色外套、挎包、浓眉和夸张表情。形象和台词为本项目新写内容，没有使用其他参赛项目的立绘、原作截图或音频。角色叫“小明同学”，不是蜡笔小新原角色，也不冒充授权联动。

## 实际作用
根据页面操作和报价结果给出调皮的提醒，表达的是“替钱包站岗”，不嘲笑用户收入、身材或饮食选择。数据计算仍由原来的报价对比器完成，角色不能改预算或作出下单决定。

| 场景 | 反应 |
|---|---|
| 同款少付但超预算 | 挑眉提醒省钱不等于买得起这份预算 |
| 用券加购反而多花 | 惊讶、汗滴，指出真实多付金额 |
| 少付且预算内 | 笑眼庆祝，引用实际差额 |
| 未找到合适方案 | 疑惑，不伪造推荐 |
| 删除到空购物篮 | 提醒先选餐品 |
| 修改预算 | 思考，提醒旧报价需重算 |
| 请求中/报错 | 等待或指导查看错误，不冒充成功 |

金额直接来自当前对比结果；表情和原创短台词由web/buddy-rules.js选择，完全本地，无模型API、语音合成或额外积分消耗。历史/模拟/本轮查询来源单独标注。

## 控制
点击角色或“再来一句”切换同一事实的另一条台词。“暂停吐槽”停止自动更新，“恢复吐槽”使用最新结果；“收起”隐藏角色区域。偏好在本机浏览器localStorage保存，保存失败不会影响比价。减少动态效果的系统偏好会关闭动画。角色在布局中，不浮在按钮上遮挡操作。

## 代码
- web/buddy-rules.js：可独立测试的事件/结果→表情/台词规则。
- web/buddy.js：页面状态、暂停、收起、换台词。
- web/index.html：SVG角色与控制按钮。
- web/style.css：表情、眨眼、动作和手机布局。
- scripts/build_preview.py：将页面与脚本合成单文件离线预览。

开发测试：python -m unittest discover -s tests -v；若已装Node，还可运行 node --test tests/test_buddy.cjs。Node不是应用运行依赖。
