# 本地可视化版本

## 启动
Python 3.10+，无第三方运行依赖。在项目目录：
```powershell
python app.py ui --open
```
打开 http://127.0.0.1:8765 ，服务只监听本机。终端保持运行，Ctrl+C关闭。端口占用可加 `--port 8766`。Windows也可双击start-ui.cmd：优先使用本机已有WorkBuddy MCP配置，没有则仅演示或读取已设置的环境变量。

## 无Token演示
默认展示一次真实历史用券报价，可以调整预算，或切换“用券反而多花”（模拟）及“预算内没找到”（历史）。这是回放，不是当前实时价。离线预览HTML也可操作案例与预算，实时模式需要本地服务。

## 实时模式
设置MCD_MCP_TOKEN，或显式指定本机配置：
```powershell
python app.py ui --config "$env:USERPROFILE\.workbuddy-ai\mcp.json" --open
```
只读取你已配置的连接器，不需要启动WorkBuddy或购买模型会员。

点击“查我的门店与券” → 输入城市与商圈 → 搜索并选择门店 → 搜索餐品、点击加号加入 → 点选适用券 → 填预算 → 计算。再次点击餐品或购物清单中的×可以移除；再次点券可取消使用。券对应餐品需已在选购列表中。最多5种单品，每种1份、默认规格、到店自取；套餐选配暂不支持。

菜单标价只是参考，实际应付来自calculate-price。用户只选择具体餐品，不默认增加无糖等条件。旧结果在门店、餐品、券或预算改变时隐藏，重新计算后展示新结果。接口失败展示错误，不伪造报价。

## 凭证及数据
浏览器不接收Token或完整couponId/couponCode，只接收当次进程内的随机券别名。报价时服务端在内存中匹配真实券。只开放固定查询接口，不提供任意工具调用、文件访问或下单能力；实时请求校验本机Host和会话CSRF标记。查询结果不自动落盘。关闭服务后，内存中的券缓存与会话结束。

这是本机工具，不应将端口转发到公网。分享试用请发源码或离线预览，各自使用自己的Token。
